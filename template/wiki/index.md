> Add one row per page: `| [[page-name]] | one-line description under 120 characters |`. Update this file with every new page. Keep the descriptions concrete: they are what a reader sees when deciding what to open.
>
> Large wikis (roughly 100+ pages): keep this file as a short map of sections and move the rows into sub-indexes (`index-<section>.md`), each linked from here. Our bench showed agents rarely open `index.md` first; they search or grep. So the index is a map for humans and a fallback for agents, not the main way to find pages. Do not over-engineer it.
