# Glossary: the terms used across these docs, defined the way the kit uses them.

**Gold page.** A wiki page that should answer a given test question. A question can have several; opening any one counts as a hit. In our set the owner confirmed them, but they were first picked from pages the agent had opened.

**Frozen copy.** A snapshot of the wiki pages (and the agent instructions file, not raw sources) taken before an experiment, so every variant runs on the same content and only the pages you deliberately changed differ.

**Baseline.** The result on the unchanged wiki, before any change. Called A in our comparisons. Variant B is aliases written into page summaries; variant C is a search tool plus an alias file.

**Alias file.** A JSON side file mapping a page slug to alternative names (nicknames, the owner's words, other-language words) and questions the page answers. It lives outside `wiki/` so the wiki pages stay English only. Ours is generated by a model from page text and is a draft until reviewed.

**Evidence rule.** A finding from the miner counts as a candidate for change only if it repeats in at least three distinct sessions. It keeps one odd session from driving edits.

**Hit versus correctness.** A hit means the agent opened a gold page. Correctness means the final answer was right. We measure hits only; a run can hit and still answer wrongly, or answer right without a hit.
